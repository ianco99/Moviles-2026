## About

This is a project developed for a school assignment, part of the "Technician in Videogame Development" degree in [Image Campus](https://www.imagecampus.edu.ar/).
The course, given by professor Rodrigo Corral, teaches basics and resources for videogame development in mobile platforms. This repository is part of the first exam,
consisting in refactoring and adapating a game project to modern platforms.
